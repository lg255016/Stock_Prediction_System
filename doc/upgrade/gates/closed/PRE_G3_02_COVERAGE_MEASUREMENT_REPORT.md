## 2. 逐月分佈

原始逐月資料在證據 JSON 的 `per_stock.<stock_id>.monthly`（每檔 8 個月的
`total_trading_days` / `covered_days` / `coverage_pct`）。

⚠ **本節刻意不把逐月數字複製進 Markdown** —— 複製一份數字過來就是製造下一個
DRIFT（`PROJECT_STATUS.md` §0.5 #5 的既有教訓）。**權威在 `PRE_G3_02_coverage_measurement.json`**，
本檔只引用，Gate 3 需要逐月數字時直接讀該檔，**覆蓋的連續性（哪幾個月是 0、
哪幾個月開始出現覆蓋）直接影響 walk-forward 的可用折數，比總比例更值得逐月查**。

**唯一在此摘述、跨四檔一致的形狀**（不是複製數字）：**每一檔的覆蓋率
逐月遞增** —— 越接近窗口尾端（越接近段 A 最新掃描的頁碼），覆蓋率越高。
與段 A 命中率序列已記載的**時代混淆方向一致**：越舊的月份、覆蓋率越低。
